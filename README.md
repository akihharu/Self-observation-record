
# Self-observation record（SOR）

## サービス概要

日々の仕事や出来事、そこから得た気づきや学びを記録するためのWebアプリです。

紙の日記を書くときに必要になる「紙・ペン・書く場所」といった環境に左右されず、スマートフォンなどから手軽に記録できることを目的としています。

---

## 作ろうと思ったきっかけ

新卒研修後、半年間毎日日記を書く必要がありました。

その日の仕事や休日にしたこと、それについての感想や学びなどを100〜150文字程度で書くというものでした。

しかし、仕事に慣れていない中で毎日手書きの日記を書くことは思っていたより負担がありました。

そこで私は、平日はその日にあったことをメモしておき、休日にまとめて指定された用紙に書くという方法を取っていました。

この方法だと休日に日記を書く時間が必要になってしまいます。

また、紙に書くためには、

- 紙
- ペン
- 書く場所

が必要です。

例えば電車を待っている時間やちょっとした休憩時間など、「書く時間はあるけど書く環境がない」ということがありました。

そこで、

> スマートフォンからその場で記録できれば、もっと手軽に日記を続けられるのではないか

と考え、このアプリを作ることにしました。

---

## 解決したいこと

紙の日記では、書くための環境を準備する必要があります。

SORではスマートフォンから記録できるようにすることで、

- 電車を待っている時間
- 移動中
- 短い休憩時間

などでも記録できるようにします。

また、途中まで書いた内容を保存できるようにすることで、後から続きを書けるようにします。

---

## 主な機能

###バックエンド実装済み

Spring BootによるREST APIとして、以下の機能を実装しています。

- ユーザー登録
- ログイン
- ログアウト
- 日記の作成
- 日記の一覧表示
- 日記の詳細表示
- 日記の編集
- 日記の削除
- 日記の下書き保存
- 日記の完成保存
- 日付変更時の重複確認と上書き処理

###フロントエンド実装予定

Reactで画面を実装し、バックエンドのREST APIと連携させる予定です。

- ログイン画面
- ユーザー登録画面
- 日記一覧画面
- 日記詳細画面
- 日記作成・編集画面
- 文字数表示
- APIとのデータ連携
---

## 今後追加したい機能

会社などによっては、最終的に紙での提出が必要になる場合があります。

そのため、将来的には入力した文章を指定されたサイズに合わせて印刷できる機能を追加したいと考えています。

その他にも、

- カレンダーから記録を確認する機能
- 記録していない日の確認
- 日記の検索機能

などを追加していきたいです。
